# Control Flow in Python 🔀

Control flow is the core of making decisions in your code. Without control flow, your program would just execute from top to bottom, one line at a time. Control flow allows your program to skip lines, repeat lines, or branch into entirely different logic paths.

![Control Flow Diagram](https://upload.wikimedia.org/wikipedia/commons/thumb/c/c5/If-Then-Else-diagram.svg/400px-If-Then-Else-diagram.svg.png)

## 1. Conditional Statements (`if`, `elif`, `else`)

In Python, the `if` statement evaluates a boolean expression. If the expression is `True`, the indented block of code beneath it is executed.

### The Basic `if`
```python
temperature = 30

if temperature > 25:
    print("It's a hot day!")
    print("Remember to drink water.")
```

### Adding `else`
If you want to execute a different block of code when the condition is `False`, use `else`:
```python
is_raining = False

if is_raining:
    print("Take an umbrella.")
else:
    print("Enjoy the sunshine!")
```

### Multiple Branches with `elif`
To check multiple conditions, use `elif` (short for "else if"):
```python
score = 85

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")
```

> [!WARNING]
> Remember that Python relies heavily on **indentation**. Missing an indent or mixing spaces and tabs will result in an `IndentationError`!

## 2. Logical Operators

You can combine multiple conditions using `and`, `or`, and `not`.

| Operator | Meaning | Example | Result |
|----------|---------|---------|--------|
| `and`    | True if BOTH are true | `True and False` | `False` |
| `or`     | True if AT LEAST ONE is true | `True or False` | `True` |
| `not`    | Inverts the boolean | `not True` | `False` |

```python
has_high_income = True
has_good_credit = False

if has_high_income and has_good_credit:
    print("Eligible for loan")
elif has_high_income or has_good_credit:
    print("Eligible for partial loan")
else:
    print("Not eligible")
```

## 3. The `while` Loop

A `while` loop repeatedly executes a block of code **as long as** the given condition is `True`.

```python
count = 1

while count <= 5:
    print(f"Count is: {count}")
    count += 1  # Don't forget to update the condition, or it will loop forever!
```

### Infinite Loops
An infinite loop never stops. This usually happens when you forget to update the variable used in the condition.

```python
# WARNING: This will run forever!
# while True:
#     print("Stuck in a loop!")
```

## 4. The `for` Loop

Python's `for` loop is designed to iterate over a sequence (like a list, tuple, dictionary, set, or string).

### Iterating over a List
```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
```

### The `range()` Function
To loop a specific number of times, use the `range()` function.
* `range(5)` generates numbers from 0 to 4.
* `range(1, 6)` generates numbers from 1 to 5.
* `range(0, 10, 2)` generates even numbers from 0 to 8 (step of 2).

```python
for i in range(1, 4):
    print(f"Iteration {i}")
```

---

## 5. Loop Control Statements (`break`, `continue`, `pass`)

Sometimes you need to alter the flow of a loop from within.

### `break`
The `break` statement completely exits the loop immediately.
```python
for num in range(1, 10):
    if num == 5:
        break
    print(num)
# Output: 1, 2, 3, 4
```

### `continue`
The `continue` statement skips the rest of the current iteration and moves to the next one.
```python
for num in range(1, 6):
    if num == 3:
        continue
    print(num)
# Output: 1, 2, 4, 5
```

### `pass`
The `pass` statement does absolutely nothing. It is used as a placeholder when syntax requires code, but you have none to write yet.
```python
if score < 50:
    pass # TODO: Implement failing grade logic later
```
