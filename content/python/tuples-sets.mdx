# Tuples & Sets in Python 🔐

In the previous lesson, we explored Lists and Dictionaries—the heavy hitters of Python data structures. However, Python has two other highly specialized and built-in data types: **Tuples** and **Sets**.

Understanding when to use these over lists or dictionaries will dramatically improve the performance, safety, and clarity of your code.

---

## 1. Tuples: Immutable Sequences

A **Tuple** is identical to a List, with one massive difference: **Tuples are immutable.** 

Once a tuple is created, you cannot add, remove, or change its items. This makes tuples faster to process and safer from accidental modification. Tuples are created using parentheses `()`.

```python
# Creating a tuple
database_credentials = ("localhost", 5432, "admin", "secret123")

# Accessing items (exactly like a list)
print(database_credentials[0])  # "localhost"
```

### Why use a Tuple instead of a List?
1. **Safety:** If you have data that should *never* change throughout the life of your program (like configuration settings, coordinate pairs, or constant mapping), putting it in a tuple guarantees it won't be modified accidentally.
2. **Dictionary Keys:** Because tuples are immutable, they are hashable. This means you can use a tuple as a key in a dictionary (which you cannot do with a list).
3. **Performance:** Tuples require less memory and are slightly faster to iterate through than lists.

### Tuple Packing and Unpacking
When you create a tuple, you "pack" values into it. Python allows you to immediately "unpack" those values into separate variables.

```python
# Packing
coordinates = (34.0522, -118.2437)

# Unpacking
lat, lng = coordinates

print(f"Latitude: {lat}")
print(f"Longitude: {lng}")
```

If you only need some of the values, you can use the `*` operator to gather the remainder:

```python
grades = (95, 85, 92, 78, 88)

first, second, *rest = grades

print(first)  # 95
print(second) # 85
print(rest)   # [92, 78, 88] (Note: the remainder is packed into a List)
```

## 2. Sets: Unique Collections

A **Set** is an unordered collection of **unique** items. Sets are written with curly braces `{}`, similar to dictionaries, but they only contain values, not key-value pairs.

```python
# Creating a set
unique_tags = {"python", "programming", "tutorial"}

# Adding an item
unique_tags.add("coding")

# Adding a duplicate item does absolutely nothing
unique_tags.add("python")

print(unique_tags) # Output: {'coding', 'programming', 'python', 'tutorial'}
```

### The Superpower of Sets: Fast Lookups
If you have a list of a million items and you want to check if a specific item exists, Python has to check every single item one by one (this is $O(N)$ time complexity).

Sets use hash tables under the hood. Checking if an item exists in a set of a million items is virtually instant (this is $O(1)$ time complexity).

> [!TIP]
> If you ever find yourself writing `if item in big_list:`, convert the list to a set first using `big_set = set(big_list)`. Your code will run significantly faster!

### Removing Duplicates from a List
The most common practical use of a set in Python is rapidly stripping duplicates from an existing list.

```python
dirty_data = [1, 2, 2, 3, 4, 4, 4, 5]

clean_list = list(set(dirty_data))

print(clean_list) # Output: [1, 2, 3, 4, 5]
```

## 3. Mathematical Set Operations

Sets in Python support all traditional mathematical set operations, allowing you to compare collections with incredibly concise syntax.

```python
data_scientists = {"Alice", "Bob", "Charlie"}
web_developers = {"Charlie", "Dave", "Eve"}

# 1. Union (|): All unique people in both groups
all_devs = data_scientists | web_developers
# {'Alice', 'Bob', 'Charlie', 'Dave', 'Eve'}

# 2. Intersection (&): People who are BOTH data scientists AND web developers
full_stack = data_scientists & web_developers
# {'Charlie'}

# 3. Difference (-): People who are data scientists but NOT web developers
pure_data = data_scientists - web_developers
# {'Alice', 'Bob'}

# 4. Symmetric Difference (^): People in one group or the other, but NOT BOTH
specialists = data_scientists ^ web_developers
# {'Alice', 'Bob', 'Dave', 'Eve'}
```

By leveraging Tuples for data integrity and Sets for high-performance math and lookups, you elevate your code from beginner-level scripts to professional, optimized Python applications!
